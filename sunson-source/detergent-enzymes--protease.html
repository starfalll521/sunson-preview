Protease enzymes for detergent formulations

SUNSON’s detergent protease range includes Excellzyme Pro G25XLR in liquid form and Excellase Pro 1125 in granular form. Protease provides the protein-targeting function in the cleaning brief.

An enzyme function linked to the stain

Proteases act on proteins, which connects this category to protein-containing stains. The finished detergent combines that function with the rest of the formulation and the conditions of washing.

Use the protease in your detergent formulation

Excellzyme Pro G25XLR is the liquid reference for liquid detergent systems; Excellase Pro 1125 is the granular reference for powder systems. Start with the protein-containing stains and the base formulation you want to evaluate.

For a liquid formula, record the addition stage, pH, temperature and exposure time, then assess compatibility and enzyme activity during storage. For a powder formula, review blending, distribution and handling against the selected product instructions.

Measure stored activity separately from cleaning performance in the finished detergent. State the stain, wash temperature, wash time and reference formula, and keep other formulation changes visible in the comparison.
